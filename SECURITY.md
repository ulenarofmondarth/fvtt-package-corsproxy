# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's security advisories](https://github.com/ulenarofmondarth/fvtt-package-corsproxy/security/advisories/new). You will get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

Issues that only affect the upstream project, [melihbirim/corsproxy](https://github.com/melihbirim/corsproxy), are best reported there too.
